# Base de datos Pokémon

Catálogo de cartas Pokémon TCG construido a partir del inventario de Google Sheets. La aplicación web está en `index.html`. Las imágenes se consultan mediante el nombre, número y expansión, con enlaces para búsqueda manual cuando no hay coincidencia exacta. El inventario original no se modifica.

Para publicar: Settings → Pages → Deploy from a branch → main /root.
